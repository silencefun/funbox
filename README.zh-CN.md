## FunBox 精选工具一键直达

每条都直达线上工具页，点开即用：

- [吃豆人](https://funboxs.top/en/games/arcade/pac-man/) — 经典迷宫追逐：吃豆子躲幽灵
- [俄罗斯方块](https://funboxs.top/en/games/arcade/tetris/) — 经典俄罗斯方块游戏
- [贪吃蛇](https://funboxs.top/en/games/arcade/snake/) — 经典贪吃蛇游戏
- [纸飞机穿梭](https://funboxs.top/en/games/arcade/flappy-bird/) — 点击控制纸飞机穿越管道
- [机器人快跑](https://funboxs.top/en/games/arcade/dino-run/) — 原创跑酷游戏，跳跃躲避障碍物
- [打砖块](https://funboxs.top/en/games/arcade/break-bricks/) — 经典打砖块游戏，挡板反弹小球
- [泡泡龙](https://funboxs.top/en/games/puzzle/bubble-shooter/) — 瞄准射击，消除三个同色泡泡
- [消消乐](https://funboxs.top/en/games/puzzle/match-3/) — 交换糖果三消，连锁得高分
- [西瓜合成](https://funboxs.top/en/games/puzzle/watermelon-merge/) — 合并相同水果合成大西瓜
- [数独](https://funboxs.top/en/games/logic/sudoku/) — 经典数独，三种难度且答案唯一
- [扫雷](https://funboxs.top/en/games/logic/minesweeper/) — 经典扫雷游戏，左键揭开右键标记
- [3D 魔方](https://funboxs.top/en/games/logic/rubik-cube/) — 纯前端 3D 三阶魔方，拖动旋转视角，转动各面并还原
- [国际象棋](https://funboxs.top/en/games/board/chess/) — 与 AI 对战完整规则国际象棋，支持将军与将杀
- [五子棋](https://funboxs.top/en/games/board/gomoku/) — 经典五子连珠，支持 AI 对战
- [台球](https://funboxs.top/en/games/sports/billiards/) — 拖动瞄准，用最少杆数清台
- [割绳子](https://funboxs.top/en/games/sports/cut-rope/) — 切断绳子让糖果落入嘴里，同时收集三颗星
- [愤怒的小鸟](https://funboxs.top/en/games/action/angry-birds/) — 拉动弹弓发射小鸟，击倒木箱砸扁绿猪
- [捏泡泡纸](https://funboxs.top/en/games/casual/bubble-wrap/) — 在线捏泡泡纸，解压放松
